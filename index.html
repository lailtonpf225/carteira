Como Instalar e Subir Seu Projeto no GitHub

Você pode hospedar gratuitamente a versão Web (GitHub Pages) ou rodar o app Python (Streamlit) com busca automática de cotações da B3.

Opção 1: Subir no GitHub e Ativar o GitHub Pages (100% Grátis)

Baixe o pacote kraken_ward_github_repo.zip gerado na conversa, extraia em uma pasta no seu computador e execute no terminal: 

git init
git add .
git commit -m "feat: plataforma Kraken & Ward de valuation e alocacao"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/kraken-ward-invest.git
git push -u origin main

Depois, no repositório do GitHub, acesse Settings → Pages → Branch: main → Save. Seu sistema ficará online no navegador!

Opção 2: Rodar a Versão Python + Streamlit (Com Cotações Ao Vivo da B3)

O pacote ZIP também inclui o arquivo app.py construído em Python + Streamlit integrado ao yfinance para puxar cotações da B3 automaticamente: 

python -m venv .venv
# No Windows: .venv\Scripts\activate
# No Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
